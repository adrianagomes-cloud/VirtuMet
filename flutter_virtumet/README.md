# flutter_virtumet

Aplicación móvil y web desarrollada en **Flutter** integrada con **Firebase** (Cloud Firestore) para la gestión de la plataforma deportiva.

## Descripción del Proyecto
 Proporcionar a la comunidad de la Universidad Metropolitana (UNIMET) una plataforma digital multiplataforma (Web y Móvil PWA) eficiente, accesible e intuitiva que centralice y automatice la gestión de clubes deportivos. VirtuMet busca optimizar el proceso de inscripción con control de cupos en tiempo real, garantizar el resguardo médico de los atletas mediante la Ficha Deportiva y fomentar la integración universitaria a través de un ecosistema social dinámico.
